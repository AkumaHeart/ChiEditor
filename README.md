# ChiEditor
Open Source video Editor Cross-platform with integrated Screen Recording

# ⚠️ Warning
This Project is still in Early Development Status, the Pre-Release 0.1.0 Alpha isn't finish yet

# OS that will be supported
- macOS (darwin kernel)
  - Apple Silicone (ARM64)
  - Apple Intel (x86_64) [⚠️ Warning: Not recommended for old devices]
- Windows
- GNU/Linux
  - Debian Native Package (.deb)
  - Flatpak
- BSD (⚠️ Not in the First Version of the app)
