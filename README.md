# 🎬 ChiEditor
Open Source video Editor Cross-platform with integrated Screen Recording :3

# ⚠️ Warning
> [!CAUTION]
> This Project is still in Early Development Status, the Pre-Release 0.1.0 Alpha isn't finish yet T-T

# 💻 OS that will be supported
- macOS (darwin kernel)
  - Apple Silicone (ARM64)
  - Apple Intel (x86_64) 
    > ⚠️ Warning: Not recommended old devices. Since i don't have the Hardware to test it, It may have some Issues, that i can't recreate or solve too fast. (RetroCompatibility will have a Full Support when I own a macBook Intel)
- Windows
  > ⚠️ Warning: Since i don't usually use Windows the fixed will going a little bit late than macOS or Linux. But I make sure that the compatibility don't break.
  - Windows x86_64 (Full Compatibility)
    - AMD (Full Compatibility)
    - Intel (Full Compatibility)
  - Windows ARM (Maybe it runs)
    - Qualcomm SnapDragon X (Maybe it runs)
    - Nvidia RTX Spark (Maybe it runs)
    > ⚠️ Warning: I'm not sure if it actually work here so run it under your own risk
- GNU/Linux
  - Debian Native Package (.deb)
  - Flatpak
- BSD 
  > Coming Soon: I'll add Partially Support enought to run in the v0.2.0
  
  > ⚠️ Warning: The app Should work on the System but, due i don't use BSD I can't Warranty to you Full Support.
